## Общая задача
Базовая задача — умножение двух квадратных матриц размера N x N.

Входные данные:
файлы с элементами исходных матриц.

Выходные данные:
файл с результирующей матрицей;
время выполнения;
размер задачи;
дополнительная информация по измерениям.
